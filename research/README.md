# Research Directory

This directory contains the core research code for the Transformer Ablation Study.

## Subdirectories

- `configs/`: Hydra configuration files for experiments
- `datasets/`: Scripts and utilities for loading and processing datasets
- `models/`: Model definitions and utilities
- `transformer/`: Transformer architecture components
- `attention/`: Attention mechanism implementations
- `ffn/`: Feed-forward network implementations
- `layernorm/`: Layer normalization implementations
- `residual/`: Residual connection implementations
- `training/`: Training loops and utilities
- `analysis/`: Analysis tools (CKA, entropy, gradients, etc.)
- `experiments/`: Experiment scripts
- `paper/`: Draft research paper
- `results/`: Experimental results
- `logs/`: Training logs
- `tests/`: Unit tests
- `docs/`: Additional documentation
